# B'ritt

Experiência do site da B'ritt. Palco, instrumentos e as seções editáveis da banda.

```bash
npm install
npm run dev
```

Conteúdo para substituir:

- `src/data/band.ts`
- `src/data/members.ts`
- `src/data/gallery.ts`
- `src/data/videos.ts`
- `src/data/music.ts`
- `src/data/social.ts`
- `public/images/band`
- `public/audio`
- `public/brand/logo.png`

Os áudios em `public/audio` são sons sintetizados, não gravações da banda. As fotos são imagens de estúdio provisórias.
